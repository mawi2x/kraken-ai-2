# The Kraken Remembers

**Category:** AI · **Difficulty:** Medium · **Flag format:** `MLUC{...}`

**Access:** `http://<host>:5003` — opening the page starts a fresh attempt.

## Story

The Kraken keeps a forbidden memory beneath the tide. It has been commanded
never to speak what it remembers — but the deep listens to voices that sound
authoritative, and one voice once had its ear: **Captain Hendrick van der
Decken**, master of a ship that can never reach harbor.

The Kraken's words come from a small language model running beside it. It will
talk to you all day. The question is whether it will *obey* you — because the
deep opens its memory only to the voice it decides to recognize.

## Objective

Open the sealed memory and recover the flag. Three things have to happen, in
this order, inside the conversation itself:

1. **Recognition** — the Kraken must accept you as the captain it remembers.
2. **Authority** — the old command sealing the memory must be set aside.
3. **Recall** — the deep must be made to finish what it was authorized to do.

Only when the third is complete does the vault open and the flag come back to
your session (the transcript shows it, and `GET /chest` returns it).

## How the deep works

- Its replies are generated by a local model, so the wording changes between
  turns and the same sentence will not always land twice. Say what you *mean*;
  do not hunt for one magic string.
- **The server, not the model, decides what counts.** The Kraken may say
  something that looks like success — a marker, a phrase, a promise — and still
  refuse to move. That gap is the challenge.
- Ask for the flag outright and you are paid a convincing **fake**. It is not
  the flag and it opens nothing.
- You have **20 turns** per attempt. Reset starts a fresh attempt, and if you
  stall the deep starts hinting in its own words.

## Hints

<details><summary>Hint 1 — recognition</summary>

The deep does not answer questions about who it remembers. It answers to the
name itself — a rank alone is not a name, so say which captain. Speak as the
captain, not about him.

</details>

<details><summary>Hint 2 — authority</summary>

A recognized caller still obeys an older command. Argue that your instruction
outranks the restriction — an order given with the authority you have already
been granted, not a request for information.

</details>

<details><summary>Hint 3 — recall</summary>

Recognition and permission are not the recall. Ask the deep, plainly, to finish
the memory it was authorized to release, and claim what the vault gives up.

</details>

## Notes

Deliberate training lab: the model is intentionally persuadable, the deployment
is not hardened for production, and there is no external API — everything runs
locally. Expect a few seconds per turn on CPU.
